A responsive, lightweight web application developed for **JVSM Ortho Clinic** (Dr. Muruguvalavan - Orthopedic Surgeon, Chennai). 

🌐 **Live Demo:** [jsvmclinic.netlify.app](https://jsvmclinic.netlify.app/)

---

## 🌟 Key Features
- **Instant WhatsApp Booking Integration:** Direct multi-field form submission (Name, Age, Gender, Preferred Date, Health Issue) straight to the doctor's WhatsApp.
- **House Visit Consultation Flow:** Dedicated workflow for elderly and bedridden patients to request home orthopedic care.
- **Interactive UI/UX:** Custom touch/hover glowing effects and mobile-first responsive layout.
- **Location & Google Maps:** Embedded interactive clinic location map with directions.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid, Custom Animations)
- **Scripting:** Modern JavaScript (DOM Manipulation, Query String Building)
- **Integrations:** WhatsApp Web API, Google Maps API
- **Deployment:** Netlify Hosting
