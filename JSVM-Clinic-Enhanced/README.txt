JSVM Orthopedic Clinic Website (Enhanced Edition)
==================================================

What's New in this Version:
- Premium Medical Color Palette (Soft teal, blue gradients, off-white background)
- Interactive Touch & Hover Effects (Buttons and tabs brighten and lift when tapped/hovered)
- Smooth shadow & card effects on Services & Doctor profile
- Clean Google Fonts (Poppins) integration

Included files:
- index.html : Main webpage layout and content
- style.css  : Design styling, interactive tab colors, and background themes

Instructions:
1. Extract (unzip) all files into a single folder.
2. Double click 'index.html' to preview the website in your browser.
3. Edit 'index.html' in any text editor to update phone numbers, text, or address.
